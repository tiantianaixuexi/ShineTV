#### ⚠️ 这套截图**不可跨轮做逐字节比对**（2026-09-30 实测）

同一个二进制连跑两轮，80 张里有 **48 张**字节不同（时钟/动画相位/日志时间戳这些天然会变）。
所以：

- ❌ 「改完再截图、和上一轮 diff」**不是**一个可用判据 —— 48 张噪声会淹没真正的 1px 变化。
- ✅ 能用的是**同轮内的重样判据**（`identical-theme-pairs` / `identical-driven-pairs`）：
  同一轮里两张本该不同的图撞了就说明有一张没拍到它承诺的状态。
- ✅ 另一个可用技巧：取「两轮之间**稳定**的那 32 张」做子集，再跨轮比 —— 但只适合
  无损重构（本轮用它在纯重构阶段验到 **32/32 未变**），不适合像素本来就该变的改动。
- 要真正做跨轮像素回归，得先把不稳定的来源（时钟/日志）钉死，那是另一件事。

### 外壳 chrome 流式布局（2026-11-23 立项，按部件一小步）

背景：外壳五部件（顶栏 / Rail / 侧栏 / 检查器 / 底栏）都是「绝对矩形 + 手算 y +
`setContentHeight`」的手绘布局，溢出 / 裁切 / 热区越界的手尾全在这条链上。
目标：换 Gallery 试点页那套**原生 ImGui 流式布局**（TreeNodeEx / Selectable /
BeginTable / 真 item 喂 ContentSize），三个手绘时代的坑随实现一起消失。

- [x] **侧栏两棵树换原生 TreeNodeEx**（2026-11-23）——`kit::Tree`（自绘行 +
  HitTestItem + 手算内容高）的三个坑**结构性消失**：
  * **跨父 id 撞车**：行 id 改由「PushID(同父下标) + 父行 TreePushOverrideID」派生，
    ImGui 的 ID 栈天生带父作用域（二十三轮手拼先序路径键防撞的那套随 `Widget_Tree` 退役）；
  * **热区越界**：行是真 item，命中与绘制同受 child 裁剪矩形管辖（原来 HitTestItem
    不看裁剪区、热区登记漏到面板外压住底栏控件 ⇒ `duplicate-hits` 0→425 那次）；
  * **setContentHeight**：真 item 自动喂 ContentSize，不再手报内容高。
  视觉层**逐位不变**（行高 28 / hover 补间 / 选中 2px accent / chevron / 图标 /
  标签截断 / 右计数 / 子层竖线）：行底铺 ColorSurface 盖掉原生箭头与背景后按设计稿重画。
  ⚠️ **hover 探针桥**：原生 item 不走 `kit::HitTestItem`，悬停计数要手动
  `NoteHoveredItem`，否则 `hover-tree-node` 把「命中数=0」读成「探针坐标点空」。
  ⚠️ `ScrollRegion` 补**原生内容回落**（Scroll.cpp 构造期）：没人自报内容高时
  `expectedMaxScrollY_` 回落 `GetScrollMaxY()`（= 上一帧 ScrollMax，静态内容帧间一致；
  自绘内容照旧必须自报，不自报 = 滚不动，判据照旧能抓）。

## 文档地图（本目录）

| 文件 | 用途 |
|---|---|
| `进度.md`（本文） | 现状层：现状 + 关键指标 + 当前计划（小步）+ 判据清单 + 视觉 1:1 符合性审计 + 没做的 |
| `轮次记录.md` | 历史层：验证记录（流水读数）、「第 N 轮」叙述块、取证快照——按标题找旧结论；只归档，不再改动 |
| `记忆.md` | **坑与纪律**：已修缺陷档案、门禁盲区、跨轮硬事实、归因纠正、开发规范 |
| `PROMPT.md` | 新会话交接提示词（开工先粘它） |
| `README.md` | 分层 + 文件地图（要改什么 → 改哪个文件） |
| `design-spec.md` | 1:1 判据与 31×5 色表 |
| `architecture.md` | 目标架构现状 |
| `phases.md` | P0–P7 历史档案（源码注释还引用它的编号） |
| `dynamic-fields.md` | 动态字段：AI 按小说风格扩展字段的机制、KV 可行性、一致性与扩展性 |
| `animations.md` | 动画体系：ImAnim 接线、通道约定、动画清单、取证确定性、imgui/ImAnim 升级记录 |
| `dpi-layout.md` | UI 体系：DPI 缩放契约、布局管理器（Stack/Row/Flow + 棘轮）、颜色对比度门禁 |

> 已删除：`PROGRESS.md`（拆入本文与记忆.md）、`component-reuse.md`（R1–R6 完成，
> 剩余小步在「当前计划」，开发规范收进记忆.md）。
