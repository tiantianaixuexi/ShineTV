## P4.1 — 共享 GPU 纹理层 + `/view` 下载  ✅ 8/8


- **S1 设备注入** — 新增 `src/gpu/GpuDevice.h/.cpp`（`AttachDevice` / `Device` / `Context` / `Ready`，内部存 `ID3D11Device*` + context）；在 `src/main.cpp:150` `ImGui_ImplDX11_Init(...)` **之后**、`app::Init()` 之前调用 `gpu::AttachDevice(...)`；打印 `log::Info("gpu device attached")`；CMake 登记。判据：运行后日志有该行、窗口正常。
- **S2 `GpuTexture`** — DX11 `Texture2D`（`DXGI_FORMAT_R8G8B8A8_UNORM`）+ SRV 封装；`width/height/bytes`；`imgui_id()` 返回 SRV 指针转 `ImTextureID`。判据：能画出一张测试图。
- **S3 `GpuTextureManager`** — `Upload(w,h,std::span<const std::byte>)` 返回 `std::expected<GpuTextureHandle, GpuError>`；`Get/Release/ReleaseAll/UsedBytes/OnDeviceLost`；**仅 UI 线程调用**。判据：创建/释放 500 次后 `UsedBytes()==0`。
- **S4 `GpuTextureCache`（通用 LRU）** — key 为 `uint64_t`（图库传 ImageId、媒体传自己的哈希），带字节预算与淘汰；**这是图库/媒体/画布共用的一份**。判据：超预算自动淘汰最久未用项。
- **S5 二进制下载** — `src/comfy/ComfyHttp.h/.cpp` 加 `HttpDownloadBinary(url, timeout=60s)` 返回 `std::expected<std::string, HttpError>`（`HttpError{status,message}`）；只在 worker 线程调。判据：下载一张 `output` 图字节成功、HTTP 404 返回错误而非崩溃。
- **S6 `/view` 取图** — `src/comfy/ComfyClient.h/.cpp` 加 `BuildViewUrl(baseUrl, fileName, subfolder, type)` 与 `FetchViewAsync(..., BinaryCb cb)`（回调 `PostToUi`）。判据：给定 `filename/subfolder/type` 能拿到字节。
- **S7 端到端画出来** — 下载字节 → libpng 解码成 RGBA8 → `gpu::Upload` → `ImGui::Image(ImTextureRef(id), size)` 显示缩略图（ImGui 1.93：`ImTextureID = ImU64`）。判据：画面出现真实缩略图。
- **S8 验收自测（4 条）** — 跑任务说明验收 1–4；**退出时无 D3D11 Live Object 报错**，结果贴 `../PROGRESS.md`。
