## P8.4 — 稳定性收尾  ⬜ 0/4


- **S1 Shutdown 顺序审计** — 顺序固定为 `mcp → paint → video → media → gallery → graph → comfy → SaveSettings → async → log`；**所有 DX11 纹理在 `main.cpp` 的 `ImGui_ImplDX11_Shutdown()` / `CleanupDeviceD3D()` 之前释放完**；worker 池销毁后不得再有 `RunOnWorker`。判据：反复开关机 10 次无崩溃、无 D3D11 Live Object 报错。
- **S2 设备丢失恢复** — `GpuTextureManager::OnDeviceLost()` 清句柄但**保留缓存条目**，下一帧按需重建。判据：人为触发设备丢失后界面能自行恢复出图。
- **S3 Worker 兜底** — 所有 worker 任务体包 `try/catch`，异常转 `log::Error` + UI 提示，**不触发 `std::terminate`**。判据：手工注入一次异常验证。
- **S4 日志落盘 + 稳定性验收** — spdlog 增加文件 sink（`%APPDATA%\ShineTVStudio\logs\`，按天滚动）+ 菜单「帮助 → 导出日志」；跑验收：连续 30 分钟反复生成 / 开关窗口 / 强制中断无崩溃无泄漏（纹理计数归零、内存平稳）；结果贴 `../PROGRESS.md`。
