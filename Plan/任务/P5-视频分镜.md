## P5.4 — H3 工作流编译器（ref2va / fl2va + 链式）  ⬜ 0/7


- **S1 骨架** — `src/video/NodeIdPool.h`（顺序发号，保证幂等）+ `H3WorkflowBuilder.h/.cpp`（`H3BuildOptions` / `H3BuildResult` / `BuildH3Workflow`）；CMake 登记。
- **S2 对齐工具** — `AlignFrameCount()`（向上对齐到 `n % 17 == 5`）+ `AlignToMultiple(32)`；单独自测打印纠正前后值。判据：`length=100 → 107`、`width=1300 → 1312`。
- **S3 模型段** — `UNETLoader` + `CLIPLoader(type=minimax)` + `VAELoader`(video) + `VAELoader`(audio) + 可选 `LoraLoader`(Turbo) → `MiniMaxH3SigmaShift`（模型级，取首段值，不一致告警）→ `KSamplerSelect(res_multistep)` → 共享 `BasicScheduler(simple)`（仅当全片 steps/denoise 一致）。
- **S4 每段 conditioning 与采样** — `Reference` 用 `MiniMaxH3ReferenceToVideo`（`audio_vae` + `ref_images.ref_image_N` **带父前缀的 dotted 路径**，无首帧）；`FirstLastFrame` 用 `MiniMaxH3ImageToVideo`（只有 `first_frame`）；负向用 `ConditioningZeroOut(正向 conditioning)`；→ `CFGGuider` → `RandomNoise` → `SamplerCustomAdvanced`（latent 取 conditioning 第 1 号输出）→ `VAEDecode` + `VAEDecodeAudio` → `CreateVideo(fps=24)` → `SaveVideo`。
- **S5 链式首尾帧** — 维护上一段解码节点，新建 `ImageFromBatch(image=上一段 VAEDecode, batch_index=对齐帧数-1, length=1)`；`Reference` 模式末帧作为**额外参考图软锚定**、`FirstLastFrame` 模式接到 `first_frame` **硬锚定**；第 1 段忽略 `chainFromPrevious`。
- **S6 收尾与异常** — `LoadImage` 按文件名去重复用；`dryRun` 用占位文件名且日志写明；异常场景（模型名为空 / 无可提交分镜 / ref2va 与 fl2va 混用）给**中文错误或告警、绝不产出半成品 JSON**。
- **S7 验收自测（4 条）** — 跑验收 1–4，重点 **同输入编译两次逐字节一致**；结果贴 `../PROGRESS.md`。

## P5.7 — 分镜图生成（SceneToImage / SD1.5 线）  ⬜ 0/5


- **S1 骨架** — `src/video/SceneToImageBuilder.h/.cpp`（编译入口 + 结果结构）；CMake 登记。
- **S2 基础 img2img 线** — `CheckpointLoaderSimple` → `CLIPTextEncode`(正/负) → `LoadImage`(颜色) → `ImageScale(lanczos)` → `VAEEncode` → `KSampler(dpmpp_2m, karras)` → `VAEDecode` → `SaveImage` + `PreviewImage`；**宽高按 64 对齐**（与 H3 的 32 不同）。判据：不给控制图也能出一张图。
- **S3 ControlNet 线** — 可选 `LoadImage(depth)` + `ControlNetLoader` + `ControlNetApplyAdvanced`；可选 `LoadImage(normal)` 同法；两个都**串接**到 conditioning 上，权重固定。
- **S4 参数与降级** — 分镜图参数进 `VideoProject`（checkpoint / ControlNet / 宽高 / steps / cfg / denoise / seed / sampler / scheduler / 输出前缀，走反射存盘）；缺控制图 → 自动降级纯 img2img + `log::Warn`。
- **S5 UI 与验收** — `ShotTableView.cpp` 分镜行「出分镜图」按钮；出图后回填该分镜"首帧图"；跑验收 3 条（含输出进输出列表与媒体库）并贴 `../PROGRESS.md`。
