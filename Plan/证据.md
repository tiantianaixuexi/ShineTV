## 横切修复 — 崩溃 + 关不掉（2026-09-17）

用户报"没有链接 ComfyUI 崩溃"。**现象**：ComfyUI 不在时启动，界面 15–25 秒后**进程自己消失**（事件日志 `Application Error 1000`，模块 `nvwgf2umx.dll`、`0xc0000005`）；`CloseMainWindow` 后窗口关但**进程永不退出**。

- **崩溃根因**：gdb 栈 `wWinMain → ImGui_ImplDX11_RenderDrawData → d3d11.dll` → `views/temp/TextureSelfCheck.cpp` 每帧「Upload → 画 → **同一帧 Release**」= 用已释放 SRV 渲染（use-after-free，随机 15–25s 才崩）。改为**跨帧保活**（首帧创建一次、句柄静态、退出由 `ReleaseAll()` 回收）。
- **退出卡死根因**：`async::Shutdown → static_thread_pool::~ → pthread_join`，worker 卡在 `hv_default_logger (hlog.c:537) → msvcrt!atexit → _onexit → RtlSleepConditionVariableCS`（libhv 默认 logger 惰性 + 非线程安全，多 worker 并发首次写日志在 `_onexit` 上死锁）。修：`comfy::EnsureLibhvReady()`（`app::Init()` 最前单线程初始化）+ `async::Shutdown()` **不再 join** + `main()` 末尾 **`std::_Exit(0)`**。
- **验收（ComfyUI 关着 = 原崩溃场景）**：60 秒全程 `Responding=True`、CPU 持续增长；事件日志零新增崩溃；`CloseMainWindow` → **0.2 秒退出、exit code 0**。

MCP 规范要求 stdout **只走 JSON-RPC**，但 `log::Init()` 无条件挂 `stdout_color_sink` ⇒ 实测 stdout 里混进 48 行日志（`[..] [info] mcp Register…`），任何严格客户端都会解析失败。修法：
- `log::Init()` 支持 `SHINE_LOG_TO_STDERR`（改挂 `stderr_color_sink`）；
- `--mcp-stdio` 分支在 `RunStdioServerMain()` **之前**用 **`_putenv_s`** 打开它。
  ⚠️ 第一版用 `SetEnvironmentVariableA` —— **无效**：它只改进程环境块，`std::getenv`（`log::Init` 读的）看不到（实测日志仍进 stdout，已改 `_putenv_s`）。

**修后实测**：stdout **2 行**（initialize 响应 + tools/call 响应），stderr **49 行**日志。

**自验**：`SHINE_NOVEL_GRAPH_CHECK=1` → **19 项全 ok**、ExitCode=0；`mcp novel 模块已注册 tools=26`（原 25）。
