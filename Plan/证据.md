## 横切修复 — 崩溃 + 关不掉（2026-09-17）

来源：用户报"没有链接 ComfyUI 崩溃"。**运行时现象**：ComfyUI 不在时启动，界面约 15–25 秒后**进程自己消失**（Windows 事件日志 `Application Error 1000`：
出错模块 `nvwgf2umx.dll`、异常码 `0xc0000005`）；`CloseMainWindow` 后窗口关闭但**进程永不退出**（CPU 冻住）。

- **崩溃**：gdb 栈 `wWinMain (main.cpp:190) → ImGui_ImplDX11_RenderDrawData (imgui_impl_dx11.cpp:328) → d3d11.dll` →
  `views/temp/TextureSelfCheck.cpp` 每帧「Upload → 画 → **同一帧 Release**」= 用已释放的 SRV 渲染（use-after-free，随机 15–25s 才崩）。
  已改为**跨帧保活**（首帧创建一次、句柄静态、退出由 `ReleaseAll()` 回收）。
- **退出卡死**：gdb 栈 `async::Shutdown → static_thread_pool::~ → std::thread::join → pthread_join` + worker
  `http_client_connect → hv_default_logger (hlog.c:537) → msvcrt!atexit → _onexit → RtlSleepConditionVariableCS`（永久等锁）。
  libhv 默认 logger 惰性 + 非线程安全，ComfyUI 连不上时多 worker 并发首次写日志即在 msvcrt `_onexit` 上死锁。
  已修：`comfy::EnsureLibhvReady()`（`app::Init()` 最前面单线程初始化）+ `async::Shutdown()` **不再 join**（泄漏线程池）+
  `main()` 末尾 `std::_Exit(0)`（显式清理 D3D 之后，跳过 CRT atexit）。
- **验收（ComfyUI 关着 = 原崩溃场景）**：60 秒全程 `Responding=True`、CPU 持续增长（2297→8531ms）、**Windows 事件日志零新增崩溃**；
  `CloseMainWindow` → **0.2 秒退出、exit code 0**；截图复核侧栏「纹理自检」4 张色块仍正常绘制。
- 详见 `坑与手法.md` §6（三条新规则：ImGui 纹理生命周期 / libhv 惰性 logger / 退出策略）与 §7。

**③ 过程中修掉的真缺陷（都是"拿真工作流"才暴露的）**
1. **v0.4 的 `links` 是数组** `[link_id, origin_id, origin_slot, target_id, target_slot, type]`；原实现只认 v1.0 对象形式，
   非对象直接 `continue` → **全部连线被静默丢弃**（实测 26 节点 / **0** 连线）。现两种形状都认，认不出的形状给告警。
2. **插口顺序不一致**：`/object_info` 的 `inputs`/`outputs` 顺序 ≠ 前端 JSON 数组顺序 → 只按下标连会大量失败（0→15 条）。
   现按 JSON 里的插口**名字**重找槽位（`ref_images.ref_image_0` → 归到父插口 `ref_images`）。
3. **插口类型语义**：ComfyUI 有并集（`"FLOAT,INT,BOOLEAN"`）、通配（`*`/`ANY`/`COMFY_MATCHTYPE_*`）、动态父插口
   （`COMFY_AUTOGROW_V3`/`COMFY_DYNAMICCOMBO_V3`），而 VNS 只做 `AllowedTypes` 求交（`VisualNode.cpp:176-211`）→ 这些一律接不上。
   `ShineComfyNode::BuildSockets()` 已拆并集 + 给通配补 `ANY`，并 override `IsValidAsNewConnection`
   （**必须连它一起覆盖**：`NodeSystem.cpp:1967-1973` 会用它复检并**断开**已有连线）→ 15→24→**33**。
4. **导入后画布空白**：官方模板坐标在 `y≈4850`，而 VNS 的 `CenterViewOnAllElements()` 在偏移超出 `GRID_SIZE` 时**静默返回 false**
   （`VisualNodeAreaRendering.cpp:763-767`）→ "计数正确、画布空白"。现导入后先把整图平移到原点附近（含分组注释框）再 `CenterView()`。

**④ 顺带核对出 P5.4 值得复核的点（未改 P5.4）**
官方 r2v 模板用 **`BasicGuider`（无负向、无 CFG）**、**没有** `MiniMaxH3SigmaShift` / `ConditioningZeroOut`；
P5.4 手写的是 `CFGGuider + ConditioningZeroOut + SigmaShift`（`/object_info` 校验能过，但不是官方式样）。
官方帧数公式 `max(5, round(秒*24)) + (5 - (max(5,round(秒*24)) % 17)) % 17` 与 `AlignFrameCount` 同口径；参考图键确认为 **0 基** `ref_images.ref_image_0…8`。

**⑤ 清理**：临时截图（`build/_p37_*.png`）与 P5.5 遗留的 `build/_oi_*.json` 已删（`build/` 现无 `_*`）；无头 ComfyUI 已 `Stop-Process`。
保留物：`%TEMP%\shine_p37_report.txt`（+ `_comfy_out.log` / `_comfy_err.log`）。

**⑥ 已知缺口（留档，未做）**：`GraphCompiler` 按 `def.inputs[i].name` 写键 → 动态父插口会写成 `ref_images`
