把 1260 行的 `src/app/App.cpp` 拆成「**壳 + 每个窗口一个目录**」，抽出可复用 UI 组件层，并把**主题颜色从硬编码变成可保存/可编辑的用户设置**（后期在设置窗口里随意调色）。

## 5. 颜色 → 用户设置（核心设计）

### 5.1 数据模型

```cpp
// theme/ThemeTokens.h（新增）
struct ThemeToken {
    const char* name;        // "accent" / "panelBg" …（与 json key 一致）
    const char* group;       // "基础" / "控件" / "状态" …（设置窗口分组折叠用）
    float ThemeColors::*member;   // 指向 25 个 token 之一
};
[[nodiscard]] std::span<const ThemeToken> Tokens();   // 唯一事实来源（UI 遍历 + 序列化共用）

// theme/Theme.h（扩展，不动现有签名）
void ApplyOverrides(const std::map<std::string, std::array<float,4>>& overrides); // 在 ApplyPreset 之后叠加
[[nodiscard]] std::string ExportOverridesJson();   // 只导出自定义过的 token（"#RRGGBBAA"）
bool ImportOverridesJson(std::string_view json);
```

### 5.2 持久化

```cpp
// AppSettings 新增一个字段（反射序列化天然支持 string，无需手写 yyjson）
std::string themeCustomJson;   // {"accent":"#4C8DFFFF","panelBg":"#1E1E22FF",…}  空 = 完全跟随预设
```

- 启动：`ApplyPresetById(themeId)` → `ImportOverridesJson(themeCustomJson)`（失败仅 `log::Warn`，不阻塞启动）；
- 设置窗口改色：改内存 → 立即 `ApplyOverrides()` → 点「保存」时 `themeCustomJson = ExportOverridesJson()` + `SaveSettings()`；
- 「重置为预设」：清空 `themeCustomJson` 并重新 `ApplyPresetById()`。

**为什么用「JSON 字符串字段」而不是 25 个独立字段**：① 反射 Settings 已支持 `std::string`，零改动；② 加新 token 时**不需要改 Settings 结构**（向后兼容）；③ 导出/导入一个文件就能分享配色。

### 5.3 设置窗口「外观」段（R-S8 交付）

```text
[预设]   下拉：深色 / 浅色 / …（theme::Presets）
[自定义] 折叠分组：基础颜色（windowBg/panelBg/childBg/text/textDim/border…）
                    强调与状态（accent/accentAlt/danger/success/navHighlight…）
                    控件（frameBg/frameHover/frameActive/header…/checkMark/sliderGrab/separator/resizeGrip）
          每个 token = ColorEdit4(name, rgba, ImGuiColorEditFlags_AlphaBar | NoInputs) + 「↺」单色重置
[操作]   「另存为预设…」「重置为预设」「导出配色文件…」「导入配色文件…」
[预览]   一小块色板（25 个 token 各画一个色块 + token 名）—— 改哪个一眼看到
```
