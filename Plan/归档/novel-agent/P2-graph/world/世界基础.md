# 世界基础层

对应 spec：`world_*` / `calendar_*` / 世界级 `secrets.scope='world'`

## entities.kind

`universe` · `world_rule` · `history` · `society` · `tech` · `culture` · `language` · `religion` · `economy` · `calendar`

## 表

### universe_details
| 列 | 说明 |
|----|------|
| entity_id | PK → entities |
| parent_id | 上级世界/位面（可空） |
| kind | world / plane / planet / isekai |
| note | 设定摘要 |

### world_rule_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| can_do | 允许什么 |
| cannot_do | 禁止什么 |
| cost | 代价/冷却 |

> 「能做什么、不能做什么」的宪法级规则；Critic 与 AuthorRules 联动。

### history_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| era | 所属纪元名 |
| summary | 朝代/战争/灾难/兴衰 |
| related_json | 关联实体 id 数组 |

### society_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| class_note | 阶级 |
| system_note | 制度 |
| law | 法律 |
| custom | 习俗（可与 culture 交叉引用） |

### tech_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| level | 科技水平描述 |
| transport | 交通 |
| comm | 通讯 |
| productivity | 生产力 |

### culture_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| art / food / dress | 艺术/饮食/服饰 |
| taboo_note | 禁忌摘要（细项可另表 customs） |

### language_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| script | 文字 |
| speakers_faction_id | 主要使用势力 |
| sample | 样例句 |

### religion_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| gods_json | 神祇实体 id 或名称数组 |
| doctrine | 教义 |
| church_faction_id | 教会势力 |
| relics_json | 圣物 |
| rituals_json | 仪式 |
| taboos_json | 禁忌 |
| heresy_note | 异端 |
| myth_note | 神话 |

### economy_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| note | 贸易/税收/商会总述 |

细粒度价格见 `entity/物品地点势力能力.md`（currency / price_samples）。

### calendar_eras / calendar_seasons
| 表 | 列 |
|----|-----|
| calendar_eras | id, name, start_note, end_note |
| calendar_seasons | id, era_id, name, ord |

事件与场景的 `time_label` 文本应对齐「纪元+季节/年」。

## 查询切片 `GetWorldSlice()`

供 ContextBuilder 拼 prompt：

- 当前纪元 + 适用 world_rule（全文）
- 涉及地点所属 culture/religion 摘要
- 活跃 economy 摘要（可选）
