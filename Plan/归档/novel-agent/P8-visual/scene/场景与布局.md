# 场景视觉与空间布局

叙事 `scenes` 已有地点/时间/POV；本分册补 **可复用的空间与站位**，避免「门一会儿左一会儿右」。

## 场景视觉基础

| 字段 | 来源/表 |
|------|---------|
| 名称、所属地点、所属章节、时间、天气、季节、时段 | scenes + location_details |
| 室内/室外、环境类型、空间大小、建筑结构、地形、高度 | scene_visuals |
| 空间关系、出入口、道路、门窗、楼梯、家具、道具、人物位置 | scene_layouts |

### scene_layouts（重要场景布局）

| 列 | 说明 |
|----|------|
| id | scene_visual_id 或 scene_id |
| layout_json | 见下结构 |
| top_view_path / front_view_path / side_view_path | 可选布局参考图（各一张） |
| canon_status | |

`layout_json` 示例结构：

```json
{
  "ground": "…",
  "main_building": "…",
  "entrance": {"x":0,"y":0,"side":"east"},
  "windows": [],
  "furniture": [{"type":"table","x":1,"y":2}],
  "characters": [{"entity_id":1,"x":2,"y":3,"pose":"sit","facing":"table"}],
  "props": [],
  "light_sources": [],
  "camera_default": {"x":0,"y":-5,"yaw":0},
  "depth": {"foreground":"…","mid":"…","background":"…"}
}
```

- 坐标系：相对场景原点；单位自定，文档写死在实现注释
- 连续生成必须引用同一 layout_id

### scene_objects（可选细表，若 json 不够查）

scene_layout_id, obj_type, entity_id, x, y, z, yaw, note
