# 小说 Agent · 大计划总纲

> 路径：`docs/compose/plans/novel-agent/`  
> 关联设计：`docs/compose/spec/novel-agent.md`（架构与客户端接口）、`docs/compose/spec/novel-studio.md`（编辑 UI / 四视图）  
> 数据：每工程 `novel.db`；技术栈：C++26 · libhv · yyjson · SQLite · shine::async · ImGui

## 目标

在 ShineTV 内实现可支撑长篇的小说 Agent：

1. 完整叙事知识图谱（可查询、可推演，不是一堆散表）
2. OpenAI Responses 客户端（同步 + 流式 + Tool Calling）
3. 记忆与上下文组装（相关切片，不全量灌 prompt）
4. Planner → Writer → Critic → Extractor 管线
5. ImGui 工作区「生成本章」端到端可用

## 依赖顺序

```
P1 OpenAI ──────────────┐
                        ├──► P4 Tools ──► P5 Agent ──► P6 UI ──► P7 MVP
P2 Graph ──► P3 Memory ─┘         │
                                  └──► P10 MCP（只读可与 P5–P7 并行）
P2 Graph ──► P8 Visual ──► P9 ImageGen
```

- **进程内** Agent 读 SQLite/Redis：**不走 MCP**，走 `src/novel` + `src/db`
- **MCP**：给外部 Agent / Responses remote / 多进程用；工具语义与 P4 对齐
- Redis：热点缓存与队列可选，SQLite 权威

## 全局纪律

以 **`RULES-HOOK.md` + 仓库 `Doc/`** 为准（AGENTS / RULES-AI / RULES-LANG / BUILD / STYLE-UI / shinetv-db）。  
下表为摘要；语言与线程冲突时以 Doc 为准：

| 项 | 约定 |
|----|------|
| 线程 | HTTP/生成只在 worker；UI 线程禁止同步 HTTP（RULES-AI §11） |
| JSON | yyjson；禁止 nlohmann |
| 错误 | `std::expected`；中文日志 spdlog |
| 写库 | Agent 写默认 `PROPOSED`；作者确认 → `CANON`；记 `audit_logs` |
| 密钥 | 仅本地 Settings/环境变量；不进仓库、不打日志 |
| CMake | 新 `.cpp` 必须手写进 `add_executable` |
| UI | 面板只在 `src/app/novel/`；业务无 ImGui；取色 theme token |
| libhv 特例 | 仅 comfy / mcp / **openai**（见 RULES-HOOK） |
| 每步 | configure → build → 运行/自检再进下一步 |
| 进度 | 只勾 `PROGRESS.md`，一次一个 ID |

## 阶段总览

| 阶段 | 名称 | 完成定义（一句话） |
|------|------|-------------------|
| P1 | OpenAI | 能拿到一段中文；能流式；能解析 output_text |
| P2 | 图谱 | 六域表可 CRUD；因果/冲突/谜/依赖可查询 |
| P3 | 记忆 | 给定章号能拼出含人物状态与未回收伏笔的 context |
| P4 | Tools | 模型 function call 能打到本地工具并返回 |
| P5 | Agent | 点一次跑完 Plan→Write→Review→Save |
| P6 | UI | 不进 CLI 也能生成并看流式正文 |
| P7 | MVP | 设定→第1章→第2章上下文一致 |
| P8 | 视觉 | 阶段状态→九层 Prompt 可组装；分镜表可存 |
| P9 | 出图 | 生成图落盘为 PROPOSED；可标 CANON |
| P10 | MCP | 外部客户端 tools/list + 只读 call 通；写默认关 |

## 视觉体系原则（P8/P9）

- 文本 Canon → 视觉 Canon → 剧情状态 → 视觉状态 → 分层 Prompt → 出图
- 生成图默认 PROPOSED，**不得**未审核反向改写设定
- 细节只写在 `P8-visual/**` 与 `P9-imagegen/`，不在总纲压缩字段

## 验收口径

- 分步判据：各 `P*/**/PLAN.md` / 分册内「验收」「任务」
- **进度只在 `PROGRESS.md` 勾选**（总览表 + P1–P10 子项 + 阻塞风险）
- 阻塞写进 PROGRESS「阻塞与风险」，不要只留在对话里
