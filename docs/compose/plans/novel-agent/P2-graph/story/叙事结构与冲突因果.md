## 主题 / 母题

### themes(id, title, statement, linked_plot_id)
例：自由 vs 命运；主题 → 弧光 → 剧情 → 冲突 → 结局

### motifs(id, symbol, meaning, first_ch, last_ch, transform_note)
例：黑鸟/雨/钟/戒指；反复出现与意义变迁
