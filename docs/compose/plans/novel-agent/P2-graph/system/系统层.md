# 系统层 · 记忆表 · Canon · 依赖 · 审计

## Canon

### canon_logs
| target_kind, target_id | 指向实体/章节/规则… |
| status | PROPOSED / DRAFT / CANON / NON_CANON |
| note, created | |

流程：Agent 提议 → PROPOSED → 作者 UI 确认 → CANON。  
未 CANON 的内容**默认不进入**稳定 Context（可配置实验开关）。

## 版本

### entity_versions
entity_id, ver, snapshot_json, note, created

核心对象（人物/世界规则/物品）大改前打快照；支持回滚对比。

## 依赖 Dependency Graph

### dependencies
| from_kind, from_id | to_kind, to_id |
| dep_type | requires / mentions / constrains / invalidates |
| note | |

语义：
- requires：from 依赖 to 成立
- mentions：from 提到 to
- constrains：from 约束写法
- invalidates：改 from 使 to 过时

编辑后：`ListPendingReview(kind,id)` → 待复查章节/实体列表（不自动改正文）。
