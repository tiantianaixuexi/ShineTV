# 物品 · 地点 · 势力 · 能力 · 资源

## 物品

### entities.kind
`clothing` · `prop` · `treasure` · `item`（+ 原 novel-studio 四类）

### item_details
| 列 | 说明 |
|----|------|
| entity_id | PK |
| item_type | weapon/armor/accessory/artifact/consumable/drug/food/book/letter/key/treasure/relic/misc |
| origin | 来源 |
| maker | 制造者 |
| props | 属性 |
| power | 能力 |
| appear_chapter | 出现章 |
| state | 完好/破损/… |
| secret_note | 物品秘密 |

### Owner History
- `entity_ownerships`：分段持有（held/stored/lost/destroyed）
- `entity_events`：acquired/transferred/upgraded/lost/destroyed…
- 查询：`GetOwnerChain(item_id)` 按 ord 输出链（古神→皇帝→盗贼→…）

### 图片
`entity_images.role='sheet'` 一张四视图；`assets/<id>/sheet.png`

## 地点

### location_details
| 列 | 说明 |
|----|------|
| parent_id | 层级：世界→大陆→国→城→建筑→房间 |
| loc_type | continent/country/city/town/village/building/room/dungeon/realm/battlefield/special |
| geo_note | 地理 |
| weather / environment | 天气环境 |
| population | 人口 |
| controlling_faction_id | 控制势力 |
| danger / resource_note | 危险与资源 |
| special_rule / history_note | 特殊规则与历史 |

### location_distances
| 列 | 说明 |
|----|------|
| from_id, to_id | |
| distance_km | |
| travel_note | 路径说明 |
| days_estimate | 防止「早晨北京下午上海」 |

工具：`travel_estimate(a,b)` 读此表。

## 势力

### faction_details
| 列 | 说明 |
|----|------|
| faction_type | nation/royal/sect/church/company/family/army/gang/academy/org/secret |
| leader_id, base_location_id | |

### faction_members
| faction_id, entity_id, role, from_chapter, to_chapter |

## 能力

### power_system_details(entity_id, note)
### ability_details
| 列 | 说明 |
|----|------|
| system_id | 所属体系 |
| ability_type | skill/spell/realm/class/talent |
| level | 等级/境界 |
| attr_note | 属性 |
| cost / limit / side_effect | 代价/限制/副作用 |

克制：`relations(from_id, to_id, rel_type='counter')`  
禁止「无敌技能」：新能力必须挂 system 且有 limit。

## 资源

### entities.kind='resource'
### resource_holdings
| owner_id, resource_id, amount, chapter_id, note |

类型：money/weapon/food/drug/mana/energy/manpower/army/info  
用于状态推演与经济一致性（金币购买力）。

- `price_samples(id, item_name, currency_id, amount, era_note, chapter_id)`
