# 人物层

对应 spec：`entity_personas` · `character_arcs` · `character_status` · `emotion_events` · `relations` · `dialogue_styles` · `character_knowledge`

## entity_personas（人设全字段）

| 列 | 需求项 |
|----|--------|
| entity_id | PK，kind=person |
| age | 基础信息 |
| appearance | 外貌 |
| personality | 性格 |
| background | 背景 |
| values | 价值观 |
| desire | 欲望 |
| goal | 目标 |
| fear | 恐惧 |
| weakness | 弱点 |
| strength | 优点 |
| ability_note | 能力（细能力链 ability 实体） |
| knowledge_note | 知识概况 |
| memory_note | 重要记忆概述 |

## character_arcs（弧光 / 成长阶段）

| 列 | 说明 |
|----|------|
| id | |
| entity_id | |
| ord | 阶段序 |
| stage | 例：懦弱少年 / 第一次杀人 / 心理变化 / 保护同伴 / 价值观冲突 / 重大选择 / 蜕变 |
| trigger_event_id | 触发事件（entities.kind=event） |
| note | |

**Agent 必须能回答：该人物当前处于哪一阶段**（取最大已触发 ord，或按最新 chapter_id 的 arc 行）。

## character_status（当前状态快照）

| 列 | 例 |
|----|-----|
| entity_id, chapter_id, location_id | |
| body_state | 受伤 |
| mind_state | 恐惧 |
| emotion_json | `{"fear":70,"anger":30,"trust":20,"sadness":60,"hope":80}` |
| goal | 逃离黑森林 |
| relation_note | 不信任苏月 |
| resource_note | 持有黑色戒指 |

## emotion_events

事件 → 情绪变化 → 写回 status。

| 列 | 说明 |
|----|------|
| entity_id, chapter_id, event_id | |
| dim | fear/anger/trust/sadness/hope… |
| delta | 增减 |
| note | |

## relations（关系层）

| 列 | 说明 |
|----|------|
| from_id, to_id | 有向；双向可两条 |
| rel_type | friend/enemy/love/master/family/rival/debt/ally/control… |
| strength | 0–100；可随章变化（多行区间） |
| from_chapter, to_chapter | 时间线 |
| reason | 例：因误会 |
| status | active/ended |

## dialogue_styles

| 列 | 例 |
|----|-----|
| sentence_len | 短句 |
| vocabulary | 词汇倾向 |
| catchphrase | 口头禅 |
| taboo_words | 忌语 |
| habit | 少废话/喜欢反问/爱用隐喻 |

## character_knowledge（泛化知情，不只 secret）

| 列 | 说明 |
|----|------|
| entity_id | 人物 |
| fact_kind | secret / world_rule / event / item… |
| fact_id | 可选 |
| fact_text | |
| knows | 0/1 |
| chapter_known | |

对白约束：`knows=0` 的事实不得让该角色直接说破。
