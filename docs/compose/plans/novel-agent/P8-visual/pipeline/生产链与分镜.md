# 生产链 · 分镜 · 一致性 · 视觉 Canon

## 端到端链

```
Novel 文本图谱
  → Story State（章/人物/物品/地点状态）
  → Scene Builder（叙事场景）
  → Scene Layout
  → Character/Item VisualState
  → Action
  → Camera → Composition → Lighting
  → Visual Description
  → Prompt Assemble
  → (P9) Image Generation
  → Visual Critic / Consistency Check
  → Prompt Revision → 重生成
  → Final Image → Visual Asset DB（PROPOSED→CANON）
```

## 角色视觉工作流（人物）

设定 → 基础视觉 → 三视图 sheet → 面部/表情 → 服装 → 装备 → 年龄段 → 剧情阶段 → 战斗/特殊 → 参考图 → Master Prompt

## 场景视觉工作流

场景结构 → 布局 → 建筑环境 → 站位道具 → 时间天气 → 光源 → 镜头构图 → 描述 → Prompt → 生成 → 检查修正 → 归档

## 视觉一致性检查（文本规则，先不依赖 CV）

| 检查 | 规则 |
|------|------|
| 发色/瞳色/发型 | 与当前 VisualState 不一致则 issue |
| 疤痕/饰品 | 应存在却未写入 prompt |
| 标志服装 | 无故变化 |
| 物品阶段 | 黑色断剑→修复→觉醒 必须同 asset 不同 stage |
| 场景布局 | 同 layout_id 门/窗方位 |
| 人数 | 与 scene_cast 一致 |
| 时间天气 | 与 scenes 一致 |
| 未登场角色 | 出现在 prompt |

输出 `visual_consistency_issues`（表或内存）→ 驱动 Prompt Revision。

## Visual Critic（P9 可接多模态）

生成后：身份/发型/服装/法宝/场景/时间/动作/人数/布局/镜头/光影/风格/多余元素。  
结果：通过 / 修订 Prompt / 人工。
