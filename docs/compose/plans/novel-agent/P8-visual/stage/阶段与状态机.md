# 视觉阶段与状态机

同一对象在剧情中变形，**不能只有一个固定 Prompt**。

## 阶段示例

| 类 | 阶段链 |
|----|--------|
| 人物 | 少年→青年→入宗→战斗→重伤→觉醒→巅峰 |
| 法宝 | 普通→封印→解封→初觉→全觉→最终形 |
| 城市 | 和平→战争→陷落→毁灭→重建 |

## 表

### visual_states

| 列 | 说明 |
|----|------|
| id | |
| asset_id | → visual_assets |
| stage_key | 如 `youth` / `sealed` / `war` |
| stage_label | 中文名 |
| ord | 阶段序 |
| from_chapter, to_chapter | 剧情区间（可空=当前） |
| appearance | 本阶段外观差异（并入 Stage Prompt） |
| materials_colors | 覆盖主档的变更 |
| clothing_asset_id | 本阶段默认服装资产 |
| item_asset_ids_json | 本阶段随身关键物品 |
| effects | 本阶段特效 |
| environment_hint | |
| canon_status | |
| note | |

### 与叙事状态绑定（强制）

```
Character → character_status(chapter) → 选 visual_states 区间含该章
Item      → entity_events / item state → 对应 stage_key
Location  → history 事件 → 环境阶段
```

生成第 N 章图时：**读库选阶段**，禁止模型自行想象年龄/装备。

### 状态机规则

- 阶段只允许按 `ord` 推进（可跳变但需 event/causal 说明）
- 跨阶段突变：Critic 报 `visual_stage` issue
- 当前阶段 = `to_chapter IS NULL` 或最大 `from_chapter ≤ N`
