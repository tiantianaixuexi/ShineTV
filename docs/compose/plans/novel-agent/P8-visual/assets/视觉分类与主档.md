# 视觉分类与主档

## 覆盖的视觉实体

| 类 | 示例 |
|----|------|
| 人物 | 基础形象、年龄段、体型脸型五官发色瞳色、印记疤痕、气质表情姿态、职业/战斗/日常/正式、受伤/老年/少年/变身/觉醒/死亡前后 |
| 服装 | 日常/战斗/礼服/宗门/军装/皇室/平民/职业/法袍/铠甲/披风/帽鞋手套饰品腰带面具；季节/地域/身份 |
| 武器法宝 | 剑刀枪弓杖法器魔器圣器神器；戒指项链手镯玉佩；书卷药丹箱令牌地图信印章；飞船坐骑机械傀儡 |
| 生物环境 | 怪物神兽植物；建筑装饰；特殊材料 |

每重要条目视觉主档字段（全量，禁止压缩进 prose）：

```
基础视觉描述 · 材质 · 颜色 · 尺寸 · 比例 · 结构 · 纹理 · 符文
光效 · 能量效果 · 使用/损坏/修复/升级/觉醒/封印/解封 状态说明
不同阶段外观 · 持有者 · 历史来源 · 出场章节
视觉参考图 · AI Prompt · Negative Prompt · 图片版本
```
