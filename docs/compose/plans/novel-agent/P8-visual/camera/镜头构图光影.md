| angle | eye_level / low / high / overhead / low_angle / bird_eye / dutch / first_person / third_person |
| position | front / side / back / over_shoulder / pov / scene_center / edge / high / low |
| focal_mm | 焦距 |
| fov | |
| dof | 景深描述 |
| focus_point | |
| aperture | |
| perspective / lens_type / camera_distance | |

## 表设计

```sql
camera_defs(id, name, payload_json, note)
composition_defs(id, name, payload_json, note)
lighting_defs(id, name, payload_json, note)
```

`payload_json` 即上表字段；shot 引用 def id 或内嵌副本。
